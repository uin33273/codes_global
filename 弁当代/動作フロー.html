動作フロー解説

弁当代チェック 動作フロー

弁当代\弁当代チェック.py

指定フォルダ内の各店舗のExcelから「弁当注文人数」列を集計し、店舗マスタと突き合わせて 注文あり／注文なし／ファイルなし の3種類に分けて1つのExcelにまとめるツール。

全体の流れ 1ファイルごとの判定ロジック 出力ファイルの色分け

全体の流れ

店舗マスタの読み込みから、最終Excelの装飾・末尾セクション追加までの流れ。

flowchart TD
    Start(["起動"]) --> Master["店舗マスタ(table_HHHL共通店舗一覧m.xlsm)を読込み\n店舗名→URL／区分の対応表を作成"]
    Master --> YM["対象年月を入力(例: 202604)"]
    YM --> YMCheck{"入力したか"}
    YMCheck -- キャンセル --> End1(["終了"])
    YMCheck -- はい --> Folder["集計対象のExcelがある\nフォルダを選択"]
    Folder --> FolderCheck{"選択したか"}
    FolderCheck -- キャンセル --> End1
    FolderCheck -- はい --> List["フォルダ内の.xlsx/.xlsを列挙\n(一時ファイル ~$ は除外)"]
    List --> Loop["進捗バー付きで1ファイルずつ判定\n(下図「1ファイルごとの判定ロジック」)"]
    Loop --> Classify{"各ファイルの結果"}
    Classify -- 注文あり --> Combined["combined_list に追加"]
    Classify -- 注文なし --> Zero["zero_shops に追加"]
    Classify -- "対象シートなし／エラー" --> SkipF["スキップ"]
    Combined --> Next{"全ファイル\n処理済みか"}
    Zero --> Next
    SkipF --> Next
    Next -- いいえ --> Loop
    Next -- はい --> Missing["マスタにはあるが\nどのファイルにも出てこなかった\n店舗を抽出(missing_shops)"]
    Missing --> AnyData{"3つのリストの\nいずれかにデータがあるか"}
    AnyData -- なし --> WarnEnd(["「データが見つかりません」\nと表示して終了"])
    AnyData -- あり --> Build["注文ありデータを区分→店舗名→日付順に並べ替え\nDownloadsに「弁当チェック_年月_日時.xlsx」として保存"]
    Build --> Deco["A列をハイパーリンク化\n店舗ごとに縞模様の背景色を適用"]
    Deco --> ZeroSec["【注文なし店舗】セクションを\n黄色ヘッダーで末尾に追加"]
    ZeroSec --> Dedup["先頭5文字が既出店舗と一致する\n類似名の店舗をmissing_shopsから除外"]
    Dedup --> MissSec["【ファイルなし店舗】セクションを\nオレンジヘッダーで末尾に追加"]
    MissSec --> Format["列幅を自動調整し\nヘッダー行を折り返し表示に"]
    Format --> Done(["完了メッセージを表示し\nファイルを開く"])

1ファイルごとの判定ロジック

上図「1ファイルずつ判定」の中身。店舗名の特定から、注文あり/なしの分岐まで。

flowchart TD
    A["ファイルを開く"] --> B{"対象年月の\nシートがあるか"}
    B -- ない --> SkipF(["このファイルはスキップ"])
    B -- ある --> C["セルB3から店舗名を取得\n(「メソッド」「パーク」は除去)"]
    C --> D{"B3が空か"}
    D -- はい --> E["ファイル名の「【店舗名】」\nパターンから推測\n(なければ「名称不明」)"]
    D -- いいえ --> F
    E --> F["店舗名・ファイル名の表記ゆれ\n(「ヶ」→「ケ」)を統一"]
    F --> G["「弁当注文人数」列と\n「日付」列を見出し文字列で検索"]
    G --> H{"見出しが\n見つかったか"}
    H -- いいえ --> SkipF
    H -- はい --> I["見出し行をヘッダーとして\nデータを再読込み"]
    I --> J["数値でない・空でもない\n記入(文字扱い)の行を抽出"]
    J --> K["数値かつ0より大きい行を抽出"]
    K --> L["両方を結合し重複除去"]
    L --> M{"結合結果が空 かつ\n合計が0以下か"}
    M -- はい --> Zero(["注文なし店舗として記録"])
    M -- いいえ --> Combined(["注文ありデータとして記録"])

店舗名の照合は「店」の有無や前後の空白を無視した正規化キーで行うため、表記ゆれがあっても同一店舗として扱われる。

出力ファイルの色分け

「弁当チェック_年月_日時.xlsx」内で使われている配色の意味。

表示箇所意味
A列(青字・下線) 元のExcelファイルへのハイパーリンク
本体行(灰色の縞模様) 同じ店舗名が続く間だけ交互に配色(店舗の区切りを見やすくする)
【注文なし店舗】ヘッダー 「弁当注文人数」が0またはデータが見つからなかった店舗(行は薄い赤 )
【ファイルなし店舗】ヘッダー マスタにはあるが対象フォルダにファイル自体が見つからなかった店舗。類似名(先頭5文字一致)は除外済み(行は薄いオレンジ )
マスタファイルの参照先は C:\Users\owner\Desktop\works\保管書類\店舗リスト\table_HHHL共通店舗一覧m.xlsm 固定(コード内にパス直書き)。
