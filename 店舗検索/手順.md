# 店舗検索ミニウィンドウ

## このアプリが何をしているか

画面右下に常に表示され続ける小さな検索ボックスです。店舗マスタのExcel(「リスト」シート)を起動時に読み込んでおき、店舗名を入力するたびにその場で絞り込み検索して、対応する区分(エリア)を一覧表示します。他の作業をしながら常時デスクトップの隅に置いておき、店舗名から区分をすぐ調べるためのツールです。

## 起動すると

- ウィンドウは画面右下(タスクバーを避けたワークエリア内)に自動で配置される
- 「常に最前面」がデフォルトONの状態で表示される
- 起動と同時にマスタExcelを読み込み、下部のステータス欄に件数(または読み込みエラー)が表示される

## 使い方

1. 「店舗名:」欄にキーワードを入力する。1文字入力するたびに自動で検索され、結果欄に「店舗名 → 区分」の一覧が表示される(大文字小文字は区別しない、部分一致)
2. 該当がない場合は「該当なし」と表示される。該当が200件を超える場合は先頭200件のみ表示される
3. 結果欄の行を選択して右クリック→「コピー」、または「すべて選択してコピー」で、店舗名と区分をコピーできる(結果欄は読み取り専用で、貼り付け・編集はできない)
4. 「常に最前面」のチェックを外すと、他のウィンドウの下に隠れるようになる
5. マスタのExcelを更新した後は、検索欄右の「更新」ボタン、または Ctrl+R で再読み込みする
6. Escキーで検索欄の入力をクリアできる

## 参照しているマスタファイル

```
C:\Users\owner\Desktop\works\保管書類\店舗リスト\table_HHHL共通店舗一覧m.xlsm
```

シート「リスト」の1行目(見出し行)から「店舗名」列と「区分」列を自動で探して読み込む。見出しの列名が変わっていたり、ファイルが見つからない・他で開いていて読み込めない場合は、ステータス欄にエラー内容が表示される。
