動作フロー解説

レクカレrename_add_area 動作フロー

レクカレリネーム\レクカレrename_add_area.py

フォルダ内の画像ファイルを店舗リストと照合し、ファイル名の先頭にエリア名を自動で付けてリネームするツール。 自動判定できないファイルは、検索ボックス付きのダイアログで手動選択する。

全体の流れ 自動判定ロジック

全体の流れ

店舗リスト読込み〜フォルダ選択〜自動/手動判定〜リネーム実行までの流れ。

flowchart TD
    Start(["起動"]) --> Load["店舗リストExcelを読み込み\n(店舗名・区分の対応表)"]
    Load --> LoadCheck{"読み込めたか"}
    LoadCheck -- いいえ --> ErrEnd(["エラー表示して終了"])
    LoadCheck -- はい --> SelectFolder["画像が入っているフォルダを選択"]
    SelectFolder --> FolderCheck{"選択したか"}
    FolderCheck -- キャンセル --> End1(["終了"])
    FolderCheck -- はい --> Classify["フォルダ内の全ファイルを判定\n(下図「自動判定ロジック」参照)"]
    Classify --> NeedConfirm{"手動確認が\n必要なファイルがあるか"}
    NeedConfirm -- なし --> Apply
    NeedConfirm -- あり --> Dialog["1件ずつ店舗選択ダイアログを表示\n(店舗名・区分で検索して選択)"]
    Dialog --> Choice{"ボタンの選択"}
    Choice -- 決定 --> Resolved["選んだ店舗のエリアを採用"]
    Choice -- この回はスキップ --> Skipped["このファイルはスキップ"]
    Choice -- 戻る --> SelectFolder
    Choice -- プログラム中止 --> Abort(["フォルダを開いて強制終了"])
    Resolved --> NextConfirm{"確認対象が\nまだあるか"}
    Skipped --> NextConfirm
    NextConfirm -- あり --> Dialog
    NextConfirm -- なし --> Apply["自動判定＋手動確認の結果から\nリネーム計画を作成(名前が重複するものは除外)"]
    Apply --> HasRename{"実行する\nリネームがあるか"}
    HasRename -- あり --> DoRename["進捗バー付きでリネームを実行\n(いったん仮名にしてから確定名へ変更)"]
    HasRename -- なし --> Result
    DoRename --> Result["結果(リネーム件数／スキップ件数／\n重複で除外した件数)をダイアログ表示"]

「戻る」を押すとフォルダ選択からやり直せる。「プログラム中止」は確認中のフォルダをExplorerで開いたうえで、保存せずに強制終了する。

自動判定ロジック(classify_files)

上図「全ファイルを判定」の中身。ファイル名の先頭番号と店舗リストの番号を突き合わせて、エリアを一意に絞り込めるかを判定する。

flowchart TD
    A["ファイル名を解析\n(先頭の数字＋残りの文字列)"] --> B{"先頭が\n数字で始まるか"}
    B -- いいえ --> Manual(["手動確認リストへ"])
    B -- はい --> C["番号を3桁ゼロ埋めに変換(num3)"]
    C --> D["店舗リストから\n同じnum3の店舗をすべて抽出"]
    D --> E["各店舗名の先頭コード(GH/KM等)を除いた地名部分が\nファイル名の地名部分に含まれるか判定"]
    E --> F{"一致した店舗の「区分」が\n何種類あるか"}
    F -- 1種類 --> Auto(["自動判定OK"])
    F -- "0種類 または 2種類以上" --> Manual

全角半角の表記ゆれや「店」の有無は正規化して吸収するが、番号が一致しても地名の一致先が複数(または0件)の場合は手動確認に回る。

店舗リストの参照先は C:\Users\owner\Desktop\works\保管書類\店舗リスト\table_HHHL共通店舗一覧m.xlsm 固定(コード内にパス直書き)。
