# 算定区分ダウンロード作業

## 起動時に出る黒いウィンドウ(コンソール)について

入力する場所ではありません。処理の進み具合を表示するだけの画面です。実際の操作は、別に出てくる小さいウィンドウで行います。

1. 「対象年月の入力」ウィンドウ → 年・月を入力して「次へ」
2. 「処理するサイトの選択」ウィンドウ → チェックボックスでサイトを選んで「OK 開始」
3. ここから黒いウィンドウにログが流れ始める(見るだけでOK)
4. 同時にブラウザが自動操作で開き、店舗を1つずつCSVダウンロードしていく(左下に進捗バーの小さいウィンドウも出る。中断したい時はそこの「⛔ 中断」ボタンかEscキー)
5. 全部終わると「完了」のメッセージが出て、ログファイルが自動で開く

> ※黒いウィンドウの✕ボタンを押して閉じると、実行中の処理ごと強制終了されます。完了メッセージが出るまでは閉じないでください。
