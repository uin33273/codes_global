算定区分CSVダウンロード 動作フロー

算定区分ダウンロード作業\算定区分CSVダウンロード.py

Playwrightでブラウザを自動操作し、HUGシステムの複数サイト(拠点)・複数店舗から 算定区分の集計CSVをまとめてダウンロードするツール。対象年月・対象サイトを毎回選び、 進捗バー付きの画面で店舗を1件ずつ順番に処理していく。

全体の流れ 1店舗ごとのダウンロード処理

全体の流れ

起動〜ログイン情報確認〜年月/サイト選択〜サイトごとの処理〜完了までの流れ。

flowchart TD
    Start(["起動"]) --> Cred["Desktop\\HUG.json から\nログイン情報を読込み"]
    Cred --> CredCheck{"ファイルが存在し\n内容が正しいか"}
    CredCheck -- いいえ --> ErrCred(["エラーダイアログを表示して終了"])
    CredCheck -- はい --> Chromium{"Chromium本体は\nインストール済みか"}
    Chromium -- いいえ --> Install["進捗ダイアログを表示し\nChromiumを自動ダウンロード"]
    Install --> InstallCheck{"成功したか"}
    InstallCheck -- いいえ --> ErrInstall(["エラーダイアログを表示して終了"])
    InstallCheck -- はい --> YM
    Chromium -- はい --> YM["対象年月を入力\n(既定値: 前月)"]
    YM --> Sites["処理するサイトを選択\n(6サイト、既定は全選択)"]
    Sites --> Log["ログファイルを作成"]
    Log --> Loop["選択した各サイトを\n1つずつ処理"]

    Loop --> SaveDir["保存先フォルダを準備\nDownloads\\算定区分データ\\年月\\サイトID"]
    SaveDir --> Exist{"保存先に既存の\nCSVがあるか"}
    Exist -- あり --> Confirm{"上書き確認\nダイアログ"}
    Confirm -- いいえ --> SkipSite["このサイトをスキップ"]
    Confirm -- はい --> Login
    Exist -- なし --> Login["ブラウザを起動し\nID/パスワードでログイン"]

    Login --> Nav["CSV出力ページへ移動"]
    Nav --> ShopList["施設(店舗)一覧を取得"]
    ShopList --> EachShop["店舗を1件ずつ処理\n(下図「1店舗ごとの処理」)"]
    EachShop --> StopCheck{"「中断」ボタンが\n押されたか"}
    StopCheck -- はい --> BreakSite["このサイトを打ち切り"]
    StopCheck -- いいえ --> NextShop{"全店舗\n処理済みか"}
    NextShop -- いいえ --> EachShop
    NextShop -- はい --> CloseBrowser["ブラウザを閉じ\n成功/失敗件数をログに記録"]

    SkipSite --> NextSite{"次のサイトが\nあり、中断されていないか"}
    BreakSite --> Summary
    CloseBrowser --> NextSite
    NextSite -- あり --> Loop
    NextSite -- なし --> Summary["全サイト分の\n成功/失敗件数を集計"]
    Summary --> Msg["完了メッセージを表示\n(「中断して終了」または「正常に終了」)"]
    Msg --> OpenLog(["ログファイルを開いて終了"])

「中断」ボタンやEscキーは即座には止まらず、処理中の店舗が終わった時点で安全に停止する。

1店舗ごとのダウンロード処理

上図「店舗を1件ずつ処理」の中身。失敗した場合は最大3回まで自動リトライする。

flowchart TD
    A["進捗バーを更新し\n店舗の処理を開始"] --> B["最大3回まで試行"]
    B --> C["CSV出力ページへ再移動"]
    C --> D["施設・年・月を選択し\n表示切替ボタンをクリック"]
    D --> E{"更新確認ダイアログが\n出るか"}
    E -- 出る --> F["ダイアログをスキップして続行"]
    E -- 出ない --> G
    F --> G["「集計一覧」印刷ボタンを確認"]
    G --> H{"ボタンが見つからない\nまたはグレーアウトか"}
    H -- はい --> Skip(["この店舗はスキップ扱い\n(成功として記録)"])
    H -- いいえ --> I["印刷ボタンをクリック"]
    I --> J["支援費・サービスコードの\nチェックボックスをON(未チェックの場合)"]
    J --> K["表示切替ボタンをクリック"]
    K --> L["CSV出力ボタンをクリックし\nダウンロードを待機"]
    L --> M{"ダウンロード成功？"}
    M -- 成功 --> N["ファイルを保存先フォルダへ保存"]
    N --> O["キャンセルボタンをクリックして\n一覧画面へ戻る"]
    O --> Success(["成功として記録"])
    M -- 失敗(例外発生) --> Retry{"試行回数は\n3回未満か"}
    Retry -- はい --> C
    Retry -- いいえ --> Fail(["失敗として記録し\n次の店舗へ"])

「印刷ボタンが見つからない／グレーアウト」は失敗ではなく「対象データなし」の扱いとして、そのまま成功扱いで次の店舗に進む。

項目内容
ログイン情報Desktop\HUG.json(id / password を含むJSON、事前配置が必要)
保存先Downloads\算定区分データ\{年月}\{サイトID}\ 配下に店舗ごとのCSV
ログDownloads\算定区分データ\logs\ 配下、実行ごとに1ファイル。完了後に自動で開く
対象サイト6サイト(01〜06、地域ごと)。チェックボックスで個別選択も一括選択も可能
処理順店舗一覧は取得した順の逆順(reversed(shops))で処理
Chromium未インストールの環境(配布先PCでの初回起動など)では、年月入力に進む前に自動ダウンロードが挟まる。
