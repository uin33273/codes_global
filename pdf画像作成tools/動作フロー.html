動作フロー解説

PDF画像作成ツール群 動作フロー

pdf画像作成tools\PDF画像位置サイズ調整.py pdf画像作成tools\イメージトリミング.py

どちらもExplorerからのドラッグ&ドロップで動く画像加工ツール。 前者はPowerPointスライド内の画像を規定サイズで中央配置し、 後者はJPEG画像の余白を自動トリミングする。

① PDF画像位置サイズ調整.py ② イメージトリミング.py

Tool 1

PDF画像位置サイズ調整.py

ファイル名は「PDF」だが、実際に開くのは .pptx(PowerPoint)ファイル。 スライド内の画像を「横長は幅12.76cm／縦長は高さ16.7cm」で余白カット後にセンター配置し、 「図NN」「QRコードNNN」ラベルを画像の左上に揃え直す。

起動モードの分岐

flowchart TD
    Start(["起動"]) --> ArgCheck{"起動時の引数は？"}
    ArgCheck -- "引数なし" --> Loop["対話ループ開始\nドラッグ&ドロップ待機"]
    ArgCheck -- "引数1つ(.pptx)" --> One["process_one を1回実行"]
    ArgCheck -- "引数4つ\n(template／スライド番号／画像／出力先)" --> CLI["CLI一括モード"]

    Loop --> Input["1行入力待ち"]
    Input --> Empty{"空 または\nexit／quit？"}
    Empty -- はい --> End1(["終了"])
    Empty -- いいえ --> Paths["ドロップされた\n全パスを分割"]
    Paths --> ProcEach["各pptxに process_one を実行"]
    ProcEach --> Open1["結果ファイルを\nos.startfileで開く"]
    Open1 --> End2(["ここでループ終了\n(次の入力待ちには戻らない)"])

    One --> Fix["fix_existing_pictures\n(画像配置ロジックへ)"]
    Fix --> Save1["「元名_加工済み.pptx」として\n同じフォルダに保存"]
    Save1 --> Open2["os.startfileで開く"]

    CLI --> LoadT["template.pptxを読み込み"]
    LoadT --> PickSlide["指定スライド番号を取得\n(既存の画像は削除)"]
    PickSlide --> Place["画像配置ロジックへ"]
    Place --> SaveCLI["output.pptxとして保存"]

「① 引数なし」で処理を1件行うと、結果を開いた時点でプログラムが終了する (ドキュメントコメントは「次のファイルを待つ」とあるが、実際のコードはそこでreturnして終了する)。

画像配置ロジック(fix_existing_pictures / place_image_centered)

flowchart TD
    A["スライド内の既存pictureを\n1枚ずつ処理(全スライド分ループ)"] --> B["対象スライドから\n既存picture要素を削除"]
    B --> C["autocrop\nほぼ白い余白をカット"]
    C --> D{"横 >= 縦？"}
    D -- はい(横長) --> E["表示幅 = 12.76cm\n高さは縦横比から自動計算"]
    D -- いいえ(縦長) --> F["表示高さ = 16.7cm\n幅は縦横比から自動計算"]
    F --> G{"幅が12.76cmを\n超えるか"}
    G -- 超える --> H["幅を12.76cmに制限し\n高さを再計算"]
    G -- 超えない --> I["そのまま"]
    E --> J["スライド中央に配置\n(左右・上下とも中央)"]
    H --> J
    I --> J
    J --> K{"「図NN」「QRコードNN」の\nラベルがあるか"}
    K -- あり --> L["ラベルの左端を画像の左端に、\n下端を画像の真上に揃える"]
    K -- なし --> M["そのまま"]

CLI一括モード(新規画像を1枚挿入)でも、既存pictureの削除以降は同じロジックを共有する。

Tool 2

イメージトリミング.py

JPEG画像1枚、またはJPEGが入ったフォルダをドロップすると、 ほぼ白い余白(既定しきい値245)を自動でカットして保存する。

起動〜処理の流れ

flowchart TD
    Start(["起動"]) --> ArgCheck{"起動時の引数は？"}
    ArgCheck -- "引数なし" --> Loop["対話ループ開始\nドラッグ&ドロップ待機"]
    ArgCheck -- "引数あり" --> Once["process_pathを1回実行\n(完了メッセージを出して終了)"]

    Loop --> Input["1行入力待ち"]
    Input --> Empty{"空 または\nexit／quit？"}
    Empty -- はい --> End1(["終了"])
    Empty -- いいえ --> Paths["ドロップされた\n全パスを分割"]
    Paths --> Each["各パスに process_path を実行\n(トリミング処理へ)"]
    Each --> HasFolder{"フォルダを\n1つでも処理したか"}
    HasFolder -- はい --> OpenF["対象フォルダを\nos.startfileで開く"]
    OpenF --> End2(["ここでループ終了\n(次の入力待ちには戻らない)"])
    HasFolder -- "いいえ(単体ファイルのみ)" --> Input

単体のJPEGだけをドロップしている間は、開いたりせずそのまま次の入力待ちに戻る。 フォルダを1つでも処理すると、そこでウィンドウは終了する。

トリミング処理(process_path)の詳細

flowchart TD
    A["process_path(パス)"] --> B{"ファイル／フォルダ／\n存在しない？"}
    B -- フォルダ --> C["フォルダ内の.jpg／.jpegを列挙\n(非再帰・名前順)"]
    C --> D{"1件も\nないか"}
    D -- はい --> E["エラー表示して終了"]
    D -- いいえ --> F["出力フォルダ名を決定\n「フォルダ名_トリミング済」\n(重複時は(1)(2)…を付与)"]
    F --> G["フォルダ内の各画像を\n1枚ずつ処理(下のH以降と同じ)"]
    G --> Ret["出力フォルダのパスを返す"]

    B -- ファイル --> H["autocrop\nほぼ白(既定しきい値245)の\n余白をカット"]
    H --> I{"単体ドロップ？\nフォルダ処理中？"}
    I -- 単体ドロップ --> J["元と同じフォルダに\n「元名_トリミング済.拡張子」で保存"]
    I -- フォルダ処理中 --> K["出力フォルダに\n元のファイル名のまま保存"]

    B -- 存在しない --> L["エラー表示"]
ドロップしたもの保存先
JPEGファイル1枚 同じフォルダに 元名_トリミング済.拡張子
フォルダ 親フォルダに フォルダ名_トリミング済(重複時は (1) (2) ...)を作成し、中の各JPEGを元のファイル名のまま保存
どちらのツールも、しきい値・規定サイズなどはスクリプト冒頭の定数(LANDSCAPE_WIDTH_CM / PORTRAIT_HEIGHT_CM / DEFAULT_THRESHOLD)を変更すれば調整できる。
