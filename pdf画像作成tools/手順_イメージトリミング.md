# イメージトリミング

## このアプリが何をしているか

JPEG画像の白い余白を自動でトリミング(切り取り)して保存するツールです。

### 使い方(通常はこちら)

1. このアプリを起動すると黒いウィンドウが開き、ファイル待ちの状態になる
2. トリミングしたい.jpg/.jpegファイル、またはそれらが入ったフォルダを、その黒いウィンドウにドラッグ&ドロップしてEnter
3. 以下のルールで保存される
   - 1枚のファイルをドロップした場合 → 同じフォルダに「`<元のファイル名>_トリミング済.拡張子`」として保存
   - フォルダをドロップした場合 → フォルダ内の.jpg/.jpegを全部処理し、その親フォルダに「`<フォルダ名>_トリミング済`」フォルダを作って保存(同名フォルダが既にある場合は (1)(2)…と連番になる)
4. フォルダを処理した場合は、完了時に保存先フォルダが自動で開く
5. 続けて別のファイル・フォルダを処理する場合は、また黒いウィンドウにドラッグ&ドロップ
6. 何も入力せず Enter、または `exit` と入力すると終了する

### もう1つの使い方(コマンドで直接指定する場合)

```
イメージトリミング.py "対象のファイルまたはフォルダのパス" [しきい値]
```

(しきい値は省略可・初期値245。数値を大きくするほど、薄い色まで余白として切り取られる)
