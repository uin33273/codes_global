動作フロー解説

カウネット処理ツール一式 動作フロー

カウネット\カウネット_run_all.py

3つのファイルで構成される一連の業務ツール。ランチャー画面から 「実績データのダウンロードと結合」→「コピペ用データの集計」の順に実行する想定。

起動ランチャー ① 実績結合 ② 集計

Entry point

カウネット_run_all.py(起動ランチャー)

常に最前面に表示される3ボタンのメニュー画面。①②はそれぞれ別モジュールの main() を呼ぶだけで、失敗してもメニューは閉じずエラーダイアログのみ表示する。

flowchart TD
    Start(["起動"]) --> Menu["メニュー画面\n(常に最前面表示)"]
    Menu --> B1["1. 実績データのダウンロードと結合を実行"]
    Menu --> B2["2. コピペ用データの集計を実行"]
    Menu --> B3["3. アプリ終了"]
    B1 --> M1["カウネット実績結合.main()\n(①へ)"]
    B2 --> M2["カウネット集計.main()\n(②へ)"]
    B3 --> End(["ウィンドウを閉じる"])
    M1 -. 例外発生時 .-> Err1["エラーダイアログを表示\nメニューは継続"]
    M2 -. 例外発生時 .-> Err2["エラーダイアログを表示\nメニューは継続"]

Step 1

カウネット実績結合.py

複数のCSVを、ファイル名末尾の4桁から判定した口座番号を付けて1本のCSVに結合する。

flowchart TD
    A(["「1. 実績データのダウンロードと結合」"]) --> B["保存済みの口座番号設定を読込み\n(初回は既定値で自動生成)"]
    B --> C["末尾4桁 ⇔ 口座番号の\n設定ダイアログを表示"]
    C --> D{"「設定完了して\nCSV選択へ」を押したか"}
    D -- キャンセル --> End1(["中断"])
    D -- はい --> E["設定を保存"]
    E --> F["処理するCSVを複数選択"]
    F --> G{"1件も\n選ばなかったか"}
    G -- はい --> End1
    G -- いいえ --> H["選んだCSVを1件ずつ処理"]
    H --> I{"ファイル名の末尾4桁が\n設定と一致するか"}
    I -- 一致しない --> Skip["そのファイルはスキップ"]
    I -- 一致する --> J["CSV読込み(5行目から, cp932)"]
    J --> K["最終行を削除"]
    K --> L["「伝票タイプ」に\n「キャンセル」を含む行を削除"]
    L --> M["口座番号列を追加"]
    M --> Next["次のファイルへ"]
    Skip --> Next
    Next --> Check{"全ファイル\n処理済みか"}
    Check -- いいえ --> H
    Check -- はい --> N{"結合できた\nデータがあるか"}
    N -- なし --> Warn["警告: 対象ファイルなし"]
    N -- あり --> O["全データを結合"]
    O --> P["Downloads\\カウネット中間データ.csv\nとして保存(cp932)"]
    P --> Done(["完了メッセージを表示"])

口座番号マッピングは Desktop\カウネット_電話_口座番号.json に保存され、次回起動時も引き継がれる。

Step 2

カウネット集計.py

①で作った中間データと店舗マスターを突き合わせ、伝票番号ごとに集計・整形してExcelに書き出す。

全体の流れ

flowchart TD
    A(["「2. コピペ用データの集計を実行」"]) --> B["手順1: 中間データCSVを選択\n(Downloadsを初期表示)"]
    B --> C{"選択したか"}
    C -- キャンセル --> End1(["中断"])
    C -- はい --> D["手順2: マスターExcelを選択\n(table_HHHL共通店舗一覧m)"]
    D --> E{"選択したか"}
    E -- キャンセル --> End1
    E -- はい --> F["マスターの「リスト」シートから\n店舗名一覧を取得"]
    F --> G["CSVを読込み、列名を整形"]
    G --> H["伝票番号ごとに税込小計を合計\n→ 合計金額"]
    H --> I["伝票番号ごとに代表商品名を選定\n(下図①参照)"]
    I --> J["お届け先部署名を\n店番付き店舗名に変換\n(下図②参照)"]
    J --> K["合計金額・取引先などの列を結合し\n電話番号→出荷日→伝票番号で並び替え"]
    K --> L["Downloads\\カウネットコピペデータ.xlsx\nに保存"]
    L --> M["電話番号ごとに背景色を交互に塗り\n「未登録」は黄色、「空欄」は紫系\n列幅を自動調整"]
    M --> N{"「未登録」の\n行があったか"}
    N -- あり --> O["警告付きの完了メッセージ"]
    N -- なし --> P["完了メッセージ"]
    O --> Q["保存したExcelを開く"]
    P --> Q

保存先のExcelがすでに開いている場合は「閉じてから再実行してください」という専用メッセージで中断する。

① 代表商品名の選定

flowchart TD
    A["伝票番号でグループ化し\n税込小計の高い順に並べる"] --> B["先頭(金額最大)の商品名を取得"]
    B --> C{"先頭が「少額受注配送料」\nかつ他にも商品があるか"}
    C -- はい --> D["少額受注配送料以外で\n最も金額が高い商品名を採用"]
    C -- いいえ --> E["先頭の商品名をそのまま採用"]
    D --> F["商品名を整形\n(スペース区切りの先頭1〜2語)"]
    E --> F
    F --> G{"同じ伝票番号に\n商品が2件以上あるか"}
    G -- はい --> H["末尾に「_他」を付与"]
    G -- いいえ --> I["そのまま"]

② お届け先部署名 → 店番付き店舗名 への変換

flowchart TD
    A["お届け先部署名"] --> B{"空欄か"}
    B -- はい --> C(["「空欄」(紫系セル)"])
    B -- いいえ --> D{"「平出事務所」か"}
    D -- はい --> E(["そのまま「平出事務所」"])
    D -- いいえ --> F["「店」「グローバル」を削除\n全角英数字を半角に統一\n「前橋青葉」→「前橋青葉町」"]
    F --> G["キーワードからプレフィックスを組立て\n(下表参照)"]
    G --> H{"店名部分が\n空になったか"}
    H -- はい --> C
    H -- いいえ --> I["「プレフィックス+店名」を\nマスター一覧と正規化して照合"]
    I --> J{"一致件数"}
    J -- 1件 --> K(["マスターの「店番+店舗名」を採用"])
    J -- "0件 or 2件以上" --> L(["「未登録」(黄色セル)"])
部署名に含まれるキーワードプレフィックス
メソッド(キッズの有無を問わず)KM
キッズ(メソッドなし)K
パークP(他と組み合わせ可: KP, KMPなど)
サカフルSF
ナーシングホームNH(「ホーム」より優先)
ホーム(グローバルホーム)GH
ツリーT

例: 「グローバルキッズメソッド岩曽店」→ KM岩曽 → マスター照合後「001KM岩曽」。 「グローバルキッズパークせんげん台店」→ KPせんげん台 → 「001KPせんげん台」。

①→②の間に受け渡されるファイルは Downloads\カウネット中間データ.csv 固定。①を実行し直すと同じ名前で上書きされる。
