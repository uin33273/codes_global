■「.pyはどこにある？」について

present_files で共有された compare_absences_gui.py は、Claudeとの会話画面から
ダウンロードした場所(通常は「ダウンロード」フォルダなど、ブラウザのダウンロード先)
に保存されています。

実行するときは、そのファイルがあるフォルダに移動してから実行してください。
例(コマンドプロンプト):
    cd Downloads
    python compare_absences_gui.py

または、フルパスを直接指定してもOKです:
    python "C:\Users\あなたの名前\Downloads\compare_absences_gui.py"

分からなくなったら、ダウンロードしたファイルを右クリック→「プロパティ」→
「場所」を見ると保存先フォルダが確認できます。


■欠席チェック君(GUI版)の使い方

【初回だけ】コマンドプロンプト(またはPowerShell)で以下を実行してライブラリを入れてください
    pip install pdfplumber tkinterdnd2

【起動】
    python compare_absences_gui.py

【使い方】
① 「①欠席時対応記録票(PDF)」の枠に、PDFファイルをドラッグ&ドロップしてください。
   (ドラッグ&ドロップが効かない場合は「PDFを選択...」ボタンからでもOKです)

② 「②カレンダー画面のテキストを貼り付け」に、社内システムのカレンダー画面の
   月表示を全選択してコピーし、そのままCtrl+Vで貼り付けてください。
   ※「対象月」欄は入力しなくても比較できます(入れても入れなくても、
     日にちの数字だけで突き合わせる仕様に修正済みです)。

③ 「③比較する」ボタンを押すと、下の「結果」欄に
     ・一致件数
     ・PDFのみ(カレンダーに欠席Ⅰが見当たらない)
     ・カレンダーのみ(PDFに○行が見当たらない)
   が表示されます。

④ 必要であれば「不一致リストをCSVで保存...」から保存できます。
